# Grafik

Ablage: `grafik/<paket>/<karten-id>.svg` (oder `.png`, mind. 600 × 400 px), verknüpft in der Karte mit `illustration: grafik/<paket>/<karten-id>.svg`.

* Nur eigene Werke oder CC-BY-SA-kompatible Quellen (Quelle im PR angeben)
* KI-generierte Bilder im PR kennzeichnen
* Keine realen Marken, Logos oder erkennbaren Personen
* Stil-Leitfaden (Farben, Schrift, Rahmen) entsteht im Issue mit dem Label `grafik`

Bis es Illustrationen gibt, druckt das Print-and-Play reine Textkarten.
