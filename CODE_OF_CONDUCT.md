# Verhaltenskodex – die Stammtisch-Regeln

Dieses Projekt lebt davon, dass Menschen mit und ohne Programmier-, Design- oder Spieleerfahrung gerne mitmachen. Darum gilt:

1. **Freundlich bleiben.** Kritik gilt immer der Karte, nie der Person. „Die Karte ist mir zu stark, weil …“ statt „Das ist Blödsinn“.
2. **Alle sind willkommen.** Unabhängig von Herkunft, Bundesland, Dialekt, Alter, Geschlecht, Behinderung, Religion, sexueller Orientierung oder Erfahrung.
3. **Österreich mit Augenzwinkern, nicht auf Kosten anderer.** Klischees dürfen liebevoll sein, aber nicht herabwürdigend gegenüber Gruppen, Regionen oder Minderheiten.
4. **Keine Belästigung**, keine persönlichen Angriffe, keine Veröffentlichung privater Daten.
5. **Geduld mit Neuen.** Jeder erste PR ist ein mutiger PR.

**Verstöße** bitte vertraulich an die Projektleitung melden (Kontaktadresse im GitHub-Profil von @Taeubel). Wir reagieren innerhalb von 7 Tagen. Mögliche Folgen reichen von einem Hinweis bis zum dauerhaften Ausschluss aus dem Projekt.

Inspiriert vom [Contributor Covenant 2.1](https://www.contributor-covenant.org/de/version/2/1/code_of_conduct/), der im Zweifel ergänzend gilt.
